# 眼球教程：让模型「眼睛跟着鼠标转」

> 目标：搞懂这个 3D 简历里「人物眼睛会追着鼠标看」是怎么做出来的，
> 以及换成你自己的模型后，怎么让眼睛也动起来。

## 一句话原理

场景代码会在模型里**按名字**找眼睛：**只要有一个 mesh 的名字里包含 `eye`**，
它就会被当成眼球，自动实现「眼睛跟着鼠标转」。名字里没有 `eye`，这个效果就不会生效（其他一切照常）。

> 对应说明见根目录 [`CLAUDE.md`](../../CLAUDE.md) 的「Making it yours after a fork」一节。

---

## 换成你自己的模型时

1. 在建模软件里，把充当眼睛的网格命名为**带 `eye`** 的名字（如 `eye` / `eyes` / `eye_L`）。
2. 正常导出 `me.glb`，替换 [`web/public/models/me.glb`](../../web/public/models/me.glb)。
3. `cd web && npm run dev`，晃动鼠标看眼睛有没有跟着转。

---

## 常见问题

- **眼睛不动？** → 检查那个 mesh 名字里是不是真的含 `eye`；导出时有没有被改名 / 合并掉。
- **想调跟随幅度或快慢？** → 本项目所有场景参数都是 [`web/src/scene/Scene.tsx`](../../web/src/scene/Scene.tsx) 顶部的普通常量（见 CLAUDE.md「Scene parameters」），在里面改即可，或直接让 AI 帮你调。
